# NEGM WEB LAB v2

## الملفات
- `index.html`: واجهة التطبيق كاملة، محرر HTML، التنقل عبر hash routes، رفع الملفات، معاينة iframe، وروابط النشر.
- `manifest.webmanifest`: إعدادات PWA للتثبيت كواجهة مستقلة.
- `sw.js`: عامل خدمة لتخزين ملفات التطبيق الأساسية مؤقتًا.
- `assets/icon.svg`: أيقونة التطبيق.
- `assets/negm.jpg`: ضع صورتك السينمائية هنا بنفس الاسم (المجلد جاهز، والصورة غير مرفقة).

## تشغيله على الهاتف كتطبيق
1. ارفع محتويات المجلد إلى مستودع GitHub.
2. فعّل GitHub Pages من Settings → Pages، واختر الفرع والمجلد المناسبين.
3. افتح الرابط المنشور عبر HTTPS في Chrome على Android.
4. اختر «تثبيت التطبيق» أو من قائمة Chrome ⋮ اختر «تثبيت التطبيق / إضافة إلى الشاشة الرئيسية».

التثبيت لا يعمل مباشرة من `file://`. الـ Service Worker يتيح تخزين واجهة التطبيق الأساسية بعد الزيارة الأولى، لكنه لا يجعل JavaScript يعمل بلا توقف في الخلفية؛ أنظمة الهاتف تتحكم في مهام الخلفية.

## الصورة
احفظ الصورة التي تريدها باسم `negm.jpg` داخل مجلد `assets` بجوار `icon.svg`. صورة الهيرو تستخدم هذا المسار: `assets/negm.jpg`.

## حدود واضحة
- رفع ZIP وفكه يتم محليًا داخل المتصفح ويعتمد على مكتبة JSZip من CDN (يحتاج إنترنت لبدء تحميل المكتبة).
- لا يوجد نشر عام تلقائي للمشاريع في هذه النسخة؛ يلزم تكامل استضافة/صلاحيات GitHub API آمنة.
- Firebase URL محفوظ في الإعدادات كمعلومة فقط؛ المزامنة غير مفعلة ولا يتم فتح قواعد Firebase للعامة.
- المعاينة المعزولة مناسبة لصفحات HTML البسيطة، وقد تحتاج المشاريع ذات المسارات النسبية أو أدوات البناء إلى استضافة حقيقية.
